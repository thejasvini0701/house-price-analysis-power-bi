# House Price Prediction & Real Estate Market Analysis Dashboard

## Project Overview
This project presents an interactive real-estate market analysis dashboard built using Microsoft Power BI. The dashboard explores housing prices, property characteristics, geographic distribution, and market trends using a housing dataset.

The dashboard helps users understand property pricing patterns, compare housing features, and explore real-estate insights through interactive visualizations.

## Dashboard Pages

### 1. Market Overview
Provides an overall summary of the real-estate dataset and housing market.

**Key Performance Indicators (KPIs):**
- Total Properties
- Average Price
- Median Price
- Average Living Area
- City Count

**Visualizations:**
- House Price Trend Over Time
- Waterfront vs Non-Waterfront Distribution
- Interactive slicers for City, Date, Bedrooms, and Waterfront

### 2. Property Analysis
Explores the relationship between property features and house prices.

**Visualizations:**
- Average Price by Bedrooms
- Average Price by Bathrooms
- Average Price by View
- Average Price by Floors

### 3. Geographic Insights
Analyzes housing distribution and pricing across different geographic locations.

**Visualizations:**
- Property Count by City
- Property Distribution by City
- Average Price by City

### 4. Additional Insights
Provides further analysis of property pricing and characteristics.

**Visualizations:**
- Average Price by ZIP Code
- Living Area vs House Price
- Average Price by Condition
